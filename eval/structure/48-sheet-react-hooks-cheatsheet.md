# React 훅 치트시트

## useState
컴포넌트 안에서 바뀌는 값을 기억한다.
- 형태: `const [값, 바꾸기] = useState(처음값)`
- 바꾸기 함수를 부르면 다시 그린다

## useEffect
그린 뒤에 할 일(데이터 불러오기, 구독)을 둔다.
- 두 번째 인자 배열의 값이 바뀔 때만 다시 실행된다
> 주의: 정리 함수를 돌려주지 않으면 구독이 쌓인다.

## useMemo
계산이 무거운 값을 기억해 두고 의존 값이 같으면 다시 계산하지 않는다.

## useRef
다시 그리지 않고 값을 담아 두거나 DOM 요소를 가리킨다.

## 고르는 법
| 하고 싶은 것 | 훅 |
|---|---|
| 화면에 보이는 값 바꾸기 | useState |
| 서버에서 불러오기 | useEffect |
| 무거운 계산 줄이기 | useMemo |
