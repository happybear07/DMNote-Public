Node.js 이미지 리사이즈 라이브러리 4종을 직접 비교해 봤습니다.

**테스트 조건**: 4000×3000 JPEG 1,000장을 800px 너비로 리사이즈, 같은 서버(8코어)에서 장당 평균 처리 시간을 측정.

**결과 (장당 평균 처리 시간)**

- sharp: 38ms
- canvas(node-canvas): 97ms
- squoosh: 156ms
- jimp: 412ms

정리하면:

1. **sharp**가 가장 빠릅니다. 내부적으로 libvips를 쓰기 때문에 jimp보다 약 10배 빠릅니다.
2. **jimp**는 순수 JavaScript라 설치가 간단하지만 대량 처리에는 부적합합니다.
3. **squoosh**는 실행 환경에 따라 편차가 커서, 여러 번 돌렸을 때 120~190ms 사이로 흔들렸습니다.
4. 메모리 사용량도 sharp가 가장 적었습니다. 다만 메모리는 정밀하게 측정하지 않았으니 참고만 해 주세요.

**추천**: 서버에서 대량으로 썸네일을 만든다면 sharp, 네이티브 의존성을 피해야 하는 환경(예: 일부 서버리스)이라면 jimp를 고려하세요.
