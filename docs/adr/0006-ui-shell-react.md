# ADR-0006: UI 셸은 React, 캔버스는 엔진 바닐라 DOM

| 항목 | 내용 |
|---|---|
| 상태 | 승인 (2026-10-01, 설계 마무리 위임에 따라 추천안 채택) |
| 날짜 | 2026-10-01 |
| 결정자 | 곰탱이 (제안: 설계 문서 작성 시) |

## 맥락

사이드바 · 설정 · 다이얼로그 · 패널 같은 일반 UI는 프레임워크 생산성이 크다. 반면 캔버스 블록은 1만 개 가상화와 "팬 · 줌 중 스타일 변경 0건"을 지켜야 해서 React 재조정과 맞지 않는다.

## 결정

앱 셸은 React 19 + TypeScript. 엔진은 React가 제공하는 컨테이너 div 하나에 마운트되고, React는 엔진 이벤트를 구독하는 얇은 훅으로만 연결된다. 캔버스 위 팝업은 포털 + 엔진 좌표 변환.

## 결과

- AI 코딩 에이전트가 가장 잘 다루는 스택이라 병렬 개발에 유리하다.
- 엔진과 UI 사이 경계(훅 · 이벤트)를 계약으로 고정해야 한다.

## 검토한 대안

- 전체 바닐라 — 일반 UI 생산성 손실
- Svelte · Solid — 생태계 · 에이전트 숙련도
