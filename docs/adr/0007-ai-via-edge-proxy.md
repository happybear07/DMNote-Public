# ADR-0007: AI 호출은 Edge 프록시 경유, tool use로 출력 강제

| 항목 | 내용 |
|---|---|
| 상태 | 승인 (2026-10-01, 설계 마무리 위임에 따라 추천안 채택) |
| 날짜 | 2026-10-01 |
| 결정자 | 곰탱이 (제안: 설계 문서 작성 시) |

## 맥락

브라우저에서 Claude API를 직접 호출하면 키가 노출된다(FR-104). 구조화 결과는 캔버스에 반영되기 전에 형식이 보장돼야 한다(FR-100). 로컬 전용 모드는 서버 없이도 AI를 쓸 수 있어야 한다.

## 결정

계정 모드는 Cloudflare Worker 프록시가 Vault의 사용자 키(BYOK)로 Claude를 호출하고 SSE로 중계한다. 출력은 `emit_structure` 도구의 input_schema로 강제하고, 클라이언트가 같은 스키마로 다시 검증한다. 로컬 전용 모드는 기기에 암호화 저장한 키로 직접 호출한다.

## 결과

- 프록시가 사용량 기록 · 레이트 리밋 · 프롬프트 캐싱의 단일 지점이 된다.
- 로컬 모드의 키 보호는 XSS 방어에 의존한다 (SECURITY 4절 고지).
- 프롬프트 · 스키마를 버전 관리하고 평가 세트로 회귀를 막는다.

## 검토한 대안

- 직접 호출만 — 키 노출
- 서비스 키만 — 비용 부담 · 남용 위험
- 자유 텍스트 응답 + 파싱 — 형식 불안정
