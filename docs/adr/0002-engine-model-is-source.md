# ADR-0002: 엔진 자체 모델이 원본, Yjs는 복제 어댑터

| 항목 | 내용 |
|---|---|
| 상태 | 승인 |
| 날짜 | 2026-10-01 |
| 결정자 | 곰탱이 (제안: 설계 문서 작성 시) |

## 맥락

동기화(FR-095 · 097)에 CRDT(Yjs)를 쓰기로 했다. Y.Doc을 처음부터 원본으로 쓰면 동기화 도입이 쉽지만, Yjs 트랜잭션은 롤백이 없고 undo 상한 · 결정적 역연산을 엔진이 통제할 수 없어 FR-002 수락 기준과 충돌한다.

## 결정

엔진의 평범한 Map 모델이 원본이다. Yjs는 Phase 5에 붙는 복제 어댑터이고, Phase 0부터 제약 C1~C10(클라이언트 id · fractional 순서 · 필드 단위 set 등)을 지켜 브리지 비용을 낮춘다.

## 결과

- Op ↔ Y.Doc 양방향 브리지를 직접 만들어야 한다 (스파이크 S4, 10/18 판정).
- 롤백 · undo · 직렬화 왕복을 평범한 객체 비교로 테스트할 수 있다.
- S4 실패 시 Y.Doc 원본으로 전환을 재검토한다 (공개 Engine API는 유지되도록 설계).

## 검토한 대안

- Y.Doc 원본 — 롤백 부재, Phase 0부터 Yjs 학습 비용
- 텍스트만 Y.XmlFragment — undo 스택 이원화
