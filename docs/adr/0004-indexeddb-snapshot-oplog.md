# ADR-0004: 로컬 저장은 IndexedDB 스냅샷 + 연산 로그

| 항목 | 내용 |
|---|---|
| 상태 | 승인 |
| 날짜 | 2026-10-01 |
| 결정자 | 곰탱이 (제안: 설계 문서 작성 시) |

## 맥락

local-first 제품이라 기기 저장소가 원본이다. 1만 블록 노트에서 매 변경마다 수 MB를 다시 쓰면 프레임을 방해하고, 엔티티마다 레코드를 두면 열기 200ms 예산을 넘는다.

## 결정

노트당 스냅샷 레코드 1개 + 추가 전용 연산 로그를 IndexedDB에 둔다. 300ms 디바운스(최대 1초)로 로그를 쓰고, 500건 · 유휴 30초 · pagehide 때 스냅샷을 다시 쓰고 로그를 비운다. 대용량 바이너리는 OPFS.

## 결과

- NoteStore 인터페이스 뒤에 숨겨 네이티브 파일 저장으로 교체할 수 있다.
- iPad Safari의 7일 미사용 삭제 문제는 배포 형태(ADR-0005)로 대응해야 한다.

## 검토한 대안

- localStorage — 동기 API · 용량
- 엔티티별 레코드 — 열기 시간
- 매번 전체 재기록 — 쓰기 비용
