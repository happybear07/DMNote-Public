# ADR-0003: 하이브리드 렌더링 (DOM 블록 + 캔버스 오버레이)

| 항목 | 내용 |
|---|---|
| 상태 | 승인 |
| 날짜 | 2026-10-01 |
| 결정자 | 곰탱이 (제안: 설계 문서 작성 시) |

## 맥락

블록은 리치 텍스트 편집 · IME · 접근성 · 임베드가 필요하고, 잉크 · 화살표는 수만 개까지 늘어날 수 있다. 전부 DOM이면 잉크가 노드 수를 폭증시키고, 전부 캔버스면 텍스트 편집 · IME를 직접 구현해야 한다.

## 결정

블록은 DOM(가상화), 자유 잉크 · 화살표 · 선택 표시는 Canvas2D 오버레이로 그린다. 팬 · 줌은 블록 레이어 래퍼 하나의 transform으로 처리한다. 화살표는 블록 아래(D4 추천안), 묶인 잉크는 블록 DOM 안의 SVG로 그린다.

## 결과

- 두 레이어의 좌표 · 줌 동기화를 엔진이 책임진다.
- 팬 · 줌 중 블록 스타일 변경 0건을 테스트로 강제할 수 있다.
- 오버레이가 예산을 넘으면 잉크 레이어만 WebGL로 전환을 검토한다.

## 검토한 대안

- 전부 DOM — 잉크 성능
- 전부 Canvas/WebGL — 텍스트 편집 · IME · 접근성 직접 구현
