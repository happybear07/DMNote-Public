# ADR-0014: 자유 배치 + 도킹, 자동 밀어내기 없음

| 항목 | 내용 |
|---|---|
| 상태 | 승인 (2026-10-02, 사용자 결정) · 고침 (2026-11-02, 사용자 결정 — 글이 늘 때 아래 상자 레고 밀기) |
| 날짜 | 2026-10-02 |
| 결정자 | 곰탱이 |

## 맥락

블록을 놓다 보면 서로 겹쳐 글자를 가린다. 사용자는 상자끼리 겹치지 않고 "레고처럼" 이어 붙기를 원했다. 한편 원하는 자리에 블록을 놓는 자유 배치는 노션식 위아래 쌓기와 구별되는 이 앱의 핵심 장점이다. 블록이 커지거나 새로 생길 때 아래 블록을 밀어내는 방식도 검토했으나 사용자가 명시적으로 거절했다. 화살표는 기능 중 하나이지 배치의 중심이 아니다.

## 결정

`packages/engine-core/src/dock.ts`의 순수 계산으로 배치를 돕고, 결과 좌표만 커맨드가 트랜잭션으로 쓴다.

- **자석 스냅** (`snapRect`): 끄는 동안 화면 10px 안에 들어온 이웃 블록의 가장자리 · 붙는 자리(간격 `DOCK_GAP` = 16)에 맞추고 안내선을 오버레이에 그린다. 옆 붙기는 세로로 마주 볼 때만, 위아래 붙기는 가로로 마주 볼 때만. Shift를 누르면 끈다. 이미 다른 블록이 있는 자리로는 스냅하지 않는다.
- **겹침 해소** (`findDockSpot`): 놓거나 만든 자리가 다른 블록과 겹치면 겹친 블록의 아래 · 옆 붙는 자리 중 가장 가까운 빈 곳으로 옮긴다(막혀 있으면 4단계까지 이어서 찾고, 그래도 없으면 나선 탐색). 드래그 놓기, 새 블록(더블클릭 · T/B 도구 · 붙여넣기 · 화살표로 새 블록 · 블록으로 분리), 복제(`duplicateBlocks {dock:true}`, 묶음의 상대 배치 유지)에 적용한다.
- **다른 블록은 움직이지 않는다**: 리사이즈해도 이웃을 밀어내지 않는다(이음매 앞에서 멈춤, `fitResize`). 움직이는 것은 사용자가 지금 놓는 블록뿐이다.
- **예외 — 글이 늘어 커질 때만 아래 상자를 레고처럼** (`flowBelow`, 2026-11-02 고침): 알파 AT-020 — 글 상자에 줄을 더하면 바로 아래 붙은 상자가 그 줄을 덮었다(캔버스 · 문서 뷰 둘 다). 사용자가 "아래 상자만 레고처럼 밀기"를 골랐다.
  - 늘면: 늘어난 상자가 이음매(16px) 안으로 닿는 아래 상자(가로로 겹치는 것)를 이음매만큼 떨어지게 내리고, 그 아래도 줄줄이. 위아래는 옮기기 전 자리로 가린다
  - 줄면: 이음매로 붙어 있고 **앞서 내려 둔 상자만** 내린 만큼까지 되돌린다(앱 메모리 — 그 뒤 사용자가 옮겼거나, 다른 상자에도 붙어 있거나, 올릴 자리가 막혔으면 그대로). 사용자가 처음부터 붙여 둔 자리 · AI 배치는 당기지 않는다
  - 옆 · 위 상자, 처음부터 겹쳐 있던 상자, 끌어 놓기 · 크기 조절은 그대로. 높이 측정과 같은 실행 취소 밖(layout) 트랜잭션
- 멀리 두면 완전히 자유 배치다.

## 결과

- 사용자가 놓은 자리를 앱이 바꾸지 않으므로 배치 의도가 보존된다. 글이 늘어 아래 상자에 닿을 때만 아래 상자가 내려간다(11/02 예외) — 글이 가려지지 않는다.
- 동기화: 내린 자리는 높이 측정처럼 각 기기가 같은 값으로 쓴다(같은 글 → 같은 높이 → 같은 자리). 되돌리기 메모리는 기기마다라 다시 열면 비워진다.
- 스냅 · 도킹은 엔진 공간 인덱스 질의만 쓰므로 1만 블록에서도 프레임 예산 안이다.
- AI 결과 배치(FR-109)는 계층형 배치 후 묶음 전체를 빈 영역에 놓는 별도 규칙(`findFreeSpot`, 간격 48)을 쓴다.

## 검토한 대안

- 노션식 쌓기(블록을 세로로만 나열) — 자유 배치 장점이 사라짐
- 자동 밀어내기(블록이 커지거나 새로 생기면 아래 블록을 밀어냄) — 사용자 거절(10/02). 놓은 자리가 바뀌고, 동기화 시 연쇄 이동 충돌이 생김. 11/02에 '글이 늘어 닿을 때만'으로 좁혀 받아들임
- 넘친 줄을 상자 안에서 스크롤 · 늘어난 상자를 위에 그리기 (11/02 검토) — 글이나 아래 상자 한쪽이 가려짐
- 겹침 그대로 허용 — 글자가 가려짐
