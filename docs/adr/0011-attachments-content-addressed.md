# ADR-0011: 첨부는 OPFS + 내용 해시 키, R2 복제

| 항목 | 내용 |
|---|---|
| 상태 | 승인 (2026-10-01, 설계 마무리 위임에 따라 추천안 채택) |
| 날짜 | 2026-10-01 |
| 결정자 | 곰탱이 (제안: 설계 문서 작성 시) |

## 맥락

이미지 · 파일 · 녹음 · PDF는 노트 스냅샷에 넣기엔 크다. 같은 파일이 여러 노트에 들어갈 수 있고, 동기화 시 재전송을 피해야 한다.

## 결정

바이너리는 OPFS에 SHA-256 해시를 키로 저장하고, 콘텐츠는 해시만 참조한다. 동기화 시 HEAD로 존재를 확인한 뒤 없을 때만 R2로 업로드한다. 파일당 100MB 상한.

## 결과

- 중복 저장 · 재전송이 없다.
- 참조 카운트 · 지연 삭제(30일) 관리가 필요하다.
- 노트 Y.Doc에는 해시만 있으므로 내용 동기화와 바이너리 동기화가 따로 진행된다 — 받는 쪽은 바이너리 도착 전 자리표시자를 보여준다.

## 검토한 대안

- IndexedDB Blob — 대용량 성능 · 할당 불리
- 노트 문서에 base64 포함 — 문서 크기 폭증
