# ADR-0005: 앱 셸은 설치형 PWA (D1)

| 항목 | 내용 |
|---|---|
| 상태 | 승인 (2026-10-01, 설계 마무리 위임에 따라 추천안 채택) |
| 날짜 | 2026-10-01 |
| 결정자 | 곰탱이 (제안: 설계 문서 작성 시) |

## 맥락

데스크톱 · 태블릿을 한 달 안에 지원해야 한다. WebKit은 7일간 상호작용하지 않은 웹사이트의 IndexedDB를 지우지만 홈 화면에 추가한 웹앱은 예외다. 네이티브 셸(Tauri 2 모바일 · Capacitor)은 펜 더블탭 · OS 키체인을 주지만 한 달 일정에 넣기 어렵다.

## 결정

모든 기기에서 설치형 PWA로 배포하고, iPad는 첫 실행 온보딩에서 홈 화면 추가를 필수로 안내한다.

## 결과

- FR-154 펜 더블탭, FR-146 OS 키체인 연동은 컷라인 아래로 간다.
- 7일 유지 실검증은 11월 초에 끝난다. 동기화(P5) 이후에는 삭제되어도 서버에서 복구된다.
- 11월에 네이티브 셸 도입을 재검토한다.

## 검토한 대안

- 데스크톱 Tauri + 태블릿 PWA — 셸 2종 유지
- 전 기기 네이티브 셸 — 일정 불가
