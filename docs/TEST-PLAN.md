---

## 1. 목표와 원칙

1. **수락 기준이 테스트다.** FR.md의 체크박스 하나하나가 자동 테스트 또는 명시된 수동 절차에 대응해야 FR을 완료로 바꿀 수 있다.
2. **데이터를 잃는 버그가 최우선이다.** 저장 · 마이그레이션 · 동기화 테스트는 컷라인과 무관하게 줄이지 않는다.
3. **AI는 결정적이지 않으므로 평가 세트로 측정한다.** 단위 테스트는 녹화된 응답(fixture)으로, 품질은 주기적 평가로 본다.
4. **병렬 개발의 통합 충돌을 테스트로 잡는다.** 계약(`packages/contracts`) 테스트를 패키지마다 둔다.

## 5. 동기화 테스트

| 테스트 | 방법 | 합격 |
|---|---|---|
| 브리지 왕복 | 무작위 Op 열 → toY → fromY → 엔진 상태 비교 | 구조적 동일 |
| 2-복제본 수렴 | 두 엔진 + 두 Y.Doc, 무작위 Op를 각자 적용 → 업데이트 무작위 순서 · 중복 · 지연 교환 → 비교 | 1만 시나리오 수렴, `normalize` 후 불변식 위반 0 |

## 6. AI 품질 평가

### 6.1 평가 세트

- `eval/structure/*.md` — 실제 AI 답변 형태의 입력 40개 (관계 설명 15 · 수치 포함 10 · 비교 10 · 혼합 5, 한국어 30 · 영어 10).
- 입력마다 기대 결과(`*.expected.json`): 반드시 있어야 할 노드 제목 · 엣지(from→to) · 차트 수치 · 표 열.
- OCR: `eval/ocr/*.png` 손글씨 30장(한글 20 · 혼용 10)과 정답 텍스트.
- Q&A(P7): 노트 묶음 1세트 + 질문 30개 + 정답 근거 노트.

### 6.2 지표와 합격선 (M2 기준)

| 지표 | 정의 | 합격 |
|---|---|---|
| 스키마 적합률 | 교정 재요청 포함 최종 유효 응답 비율 | ≥ 99% |
| 노드 재현율 | 기대 노드 중 생성된 비율 (제목 정규화 비교) | ≥ 0.85 |
| 엣지 정밀도 | 생성 엣지 중 기대 엣지에 맞는 비율 | ≥ 0.75 |
| 수치 정확도 | 차트 점 값이 원문 수치와 일치 | 100% (지어낸 수치 0) |
| 표 열 일치 | 기대 열 이름 포함률 | ≥ 0.9 |
| 출처 일치 | `source.quote`가 원문에서 발견되는 비율 | ≥ 0.9 |
| 지연 | 청크 1개 p50 / p95 | ≤ 12초 / 25초 |
| OCR CER (P4) | 문자 오류율 | 한글 ≤ 10% (미달 시 K6 대응) |
| Q&A 근거 재현율 (P7) | 정답 근거가 상위 8개 조각에 포함 | ≥ 0.8 |

### 6.3 회귀 관리

- 프롬프트(`structure.vN`) · 모델 · 스키마를 바꾸면 평가를 돌리고 결과를 `eval/results/YYYY-MM-DD-<변경>.json`으로 커밋한다.
- 합격선 미달이면 변경을 머지하지 않는다.

- 회귀 판정: 10% 규칙은 p25를 "기기 전체 drift(모든 지표 변화의 중앙값)"로 나눠 본다. 이 개발 PC는 실행마다 기기 전체 속도가 15~30% 흔들려 원시 비교로는 매번 실패했다. 0.05ms 미만 차이는 잡음으로 본다.
- 열기 40ms 목표 미달의 내역(판정 시점): `deserialize` 약 29ms(대부분 `Object.entries`로 큰 레코드 맵을 도는 비용) + 엔진 구축 약 26ms. → `for…in` 순회로 바꿔 해결(ENGINE 21절).
- FR-001 빈틈 (`api-surface.test.ts`의 `it.fails`): ① 반환 레코드가 `Object.freeze`되지 않음 (ENGINE 2.4 개발 빌드 규칙) ② 커밋이 끝난 `Tx`를 붙잡아 두면 트랜잭션 밖에서 상태를 바꿀 수 있음 (이벤트 · undo 없이). 둘 다 타입으로는 막혀 있어 정상 경로에서는 일어나지 않는다. → **10/02 해결**: ① 개발 빌드 · 테스트에서 `setDevChecks(true)`가 엔진이 저장하는 레코드를 얕게 동결(앱은 `import.meta.env.DEV`, 테스트는 루트 `vitest.setup.ts`) ② 끝난 트랜잭션의 `Tx`에 쓰면 예외. `it.fails` 두 건은 일반 테스트로 바뀌었다.
