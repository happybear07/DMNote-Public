# DamianNote 개인정보 처리방침

시행일: 2026년 10월 31일

[운영자 이름](이하 "운영자")은 DamianNote 로컬 전용판을 운영하면서 개인정보를 어떻게 다루는지 다음과 같이 알려 드립니다.

## 1. 한눈에 보기

- 노트는 이용자 기기의 브라우저 저장소에만 저장되고, 운영자 서버로 오지 않습니다. **운영자는 이용자의 노트 · 이름 · 이메일 같은 개인정보를 받거나 저장하지 않습니다.**
- 계정 · 로그인 · 분석 도구 · 광고 · 오류 수집이 없고, 운영자는 쿠키를 쓰지 않습니다.
- AI 기능을 쓰면 그 기능에 필요한 내용이 이용자 기기에서 Anthropic(미국)으로 바로 전송됩니다(3절).

## 2. 이용자 기기에만 저장되는 것

아래 정보는 이용자 기기의 브라우저 저장소에만 있고 운영자에게 전송되지 않습니다.

| 항목 | 지우는 방법 |
|---|---|
| 노트 · 필기 · 첨부 · 녹음 · 버전 기록 · 백업 | 노트 삭제(휴지통에서 30일 뒤 자동으로 영구 삭제), 또는 브라우저의 사이트 데이터 삭제 |
| 설정 · AI 사용량(요청 수 · 토큰 수) | 설정 › AI › 사용량 초기화, 또는 사이트 데이터 삭제 |
| Anthropic API 키(이 기기에서 암호화) | 설정 › AI › 키 삭제 |
| 앱 파일(오프라인 실행용 캐시) | 사이트 데이터 삭제 |
| 받아쓰기 모델(녹음 받아쓰기를 처음 쓸 때 내려받은 음성 인식 모델, 약 250MB) | 사이트 데이터 삭제 |

노트를 영구 삭제해도 그 노트의 백업 사본(노트마다 최근 5개)과 첨부 파일은 기기에 남을 수 있습니다. 브라우저의 사이트 데이터를 지우면 모두 지워집니다.

## 3. AI 기능을 쓸 때 국외로 전송되는 정보

AI 기능은 이용자가 처음 쓸 때 아래 내용을 알리고 동의를 받은 뒤에만 동작합니다. 노트에 개인정보가 들어 있으면 그 정보도 함께 전송됩니다.

| 알릴 사항 | 내용 |
|---|---|
| 받는 자 | Anthropic, PBC (연락처: privacy@anthropic.com) |
| 받는 나라 | 미국 |
| 전송 항목 | AI로 구조화하기: 고른 글(손글씨에서 읽은 글 포함) / 손글씨를 글로: 고른 필기를 그린 그림(PNG) / AI로 고치기: 고른 글(이어 쓰기 · 번역 포함) / AI로 초안 쓰기: 이용자가 쓴 주제 / AI로 노트 요약: 노트 제목과 노트 전체 글(표 · 데이터베이스 · 화살표 목록 포함) / AI로 노트 번역: 노트 제목과 글(글 상자 · 화살표 이름 · 묶음 이름) / 노트에 묻기: 질문, 고른 범위의 이름(폴더 · 태그 · 역할 · 노트 제목), 같은 창의 앞선 문답, 범위 안 노트에서 고른 조각(노트 제목 · 글 — 손글씨에서 읽은 글 포함 · 수정일). 인터넷 연결 과정에서 IP 주소 등 접속 정보도 전달됩니다 |
| 전송 시기와 방법 | 이용자가 AI 기능을 실행할 때마다, 이용자 기기의 브라우저에서 암호화된 연결(HTTPS)로 바로 전송합니다. 운영자 서버를 거치지 않습니다 |
| 받는 자의 이용 목적 | 요청한 AI 결과를 만들어 돌려주기 |
| 보유 · 이용 기간 | Anthropic 기준으로 받은 날부터 30일 안에 삭제합니다. 다만 이용 정책 위반으로 판정되면 입력 · 출력을 최대 2년 보관할 수 있고, 법령에 따라 더 보관할 수 있습니다. Anthropic은 API로 받은 내용을 모델 학습에 쓰지 않는다고 밝히고 있습니다 |
| 거부 방법과 효과 | 처음 묻는 창에서 동의하지 않거나 설정 › AI › 전송 동의 철회를 누르면 됩니다. 거부해도 노트 · 필기 · 검색 · 내보내기 등은 그대로 쓸 수 있고, AI 기능만 쓸 수 없습니다 |

- AI 기능은 이용자 본인의 Anthropic API 키로 동작하므로, Anthropic에서의 처리는 키 주인인 이용자와 Anthropic 사이의 약관과 [Anthropic 개인정보 방침](https://www.anthropic.com/legal/privacy)을 따릅니다.
- 다른 사람의 개인정보(회의 참석자 연락처 등)나 건강 · 법률 · 금융 같은 민감한 내용은 보내기 전에 빼 주세요.
- 전송 항목이나 받는 자가 바뀌면 다시 알리고 동의를 받습니다.

## 4. 그 밖에 밖으로 나가는 요청

- **웹 임베드 · 북마크 그림** — 노트에 넣은 영상 · 지도 · 그림을 보여 주려고 브라우저가 그 사이트(YouTube · Vimeo · Google 지도 등)에 직접 요청합니다. 그 사이트는 이용자의 IP 주소와 브라우저 정보를 받을 수 있으며, 각 사이트의 개인정보 처리방침을 따릅니다(예: [Google 개인정보처리방침](https://policies.google.com/privacy)). YouTube 영상은 쿠키를 줄인 youtube-nocookie 주소로 엽니다.
- **받아쓰기 모델 내려받기** — 녹음을 글로 받아쓰기를 처음 쓸 때 브라우저가 Hugging Face(huggingface.co · hf.co, 미국)에서 음성 인식 모델 파일을 한 번 내려받습니다. 받아쓰기는 이 기기 안에서 하므로 **녹음 · 노트는 보내지 않습니다.** Hugging Face는 일반적인 접속 기록(IP 주소 · 시각 · 브라우저 정보)을 남길 수 있으며 [Hugging Face 개인정보 방침](https://huggingface.co/privacy)을 따릅니다.
- **앱 파일 내려받기** — 앱 파일을 내려주는 호스팅 서비스(Cloudflare)는 일반적인 접속 기록(IP 주소 · 시각 · 브라우저 정보)을 남길 수 있습니다. 운영자는 이 기록으로 이용자를 식별하거나 분석하지 않습니다.

## 5. 이용자의 권리

노트는 이용자 기기에 있으므로 이용자가 직접 열람 · 고침 · 삭제 · 내보내기를 할 수 있습니다. 운영자는 이용자의 노트를 갖고 있지 않아 대신 열람하거나 삭제해 드릴 수 없습니다. Anthropic으로 전송된 정보에 대한 권리는 Anthropic(privacy@anthropic.com)에 요청할 수 있습니다.

## 6. 파기

운영자가 보관하는 이용자 개인정보는 없습니다. 기기에 있는 정보는 2절의 방법으로 이용자가 지울 수 있습니다.

## 7. 안전성 확보 조치

- API 키는 이 기기에 암호화해 보관하고, 보안 연결(https)에서만 저장할 수 있습니다.
- 노트 잠금을 쓰면 그 노트를 비밀번호로 암호화합니다.
- 앱은 허용한 주소(Anthropic API 등) 말고는 데이터를 보내지 못하도록 콘텐츠 보안 정책(CSP)을 씁니다.
- 같은 기기를 쓰는 다른 사람은 브라우저 저장소를 볼 수 있으므로, 여러 사람이 쓰는 기기에서는 노트 잠금을 쓰거나 이용을 피해 주세요.
